# Third-party assets in this directory

## `wtk1-prelude1.mid`

Johann Sebastian Bach, *Das Wohltemperierte Clavier I, Praeludium I* (BWV 846).

- Source: [Mutopia Project](https://www.mutopiaproject.org/) —
  `ftp/BachJS/BWV846/wtk1-prelude1/wtk1-prelude1.mid`
- Typeset by Tobias Erbsland; the LilyPond source declares
  `copyright = "Public Domain"` and states that the typesetter placed it in the
  public domain.
- The composition itself has been in the public domain for roughly two
  centuries.

Used as the default melodic score for generated audio previews. It earns the
place on merit rather than convenience: arpeggiated, harmonically unambiguous,
no percussion, and it sits in a register most instruments can play — so one
file is a fair test of a virtual analog, an FM synth and a rompler alike.

Redistribution here is permitted by its public-domain dedication. Keep this
file beside it.
