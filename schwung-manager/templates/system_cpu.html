CPU

About these numbers

Two different quantities. They cannot be added together.

Frame budget — core 3
Per-module time as a share of the {{.FramePeriodUs}} µs SPI frame period. This is the number that decides whether you get dropouts. Modules are not processes — every synth and effect runs inside MoveOriginal on the SPI callback — so this is the only per-module attribution that exists.
Process CPU — cores 0–3
Ordinary per-process percentages from /proc, measured as a share of one core — 100% is one core saturated, not the whole device. The Link Audio subscriber is a real process and appears here.

Collection in the shim is always on and costs nothing measurable. This button starts the polling, which is the only part with a real cost — and it runs off the realtime path.
