# === Notes ===
#
# All AF_UNIX SOCK_DGRAM sockets are libc resolver / nscd-probe pattern
# (DNS thread tid 1490 in Pass B opened 728 of these in 90s — no UDS
# connects fired, so they're transient probes that fail and fall back
# to direct DNS).
#
# All AF_INET / AF_INET6 connects are cloud-auth (Google Cloud LB at
# 34.160.81.0:443 + ::1:53 DNS). Same in both passes.
#
# All AF_NETLINK binds are libc's NETLINK_ROUTE interface lookup
# (`if_nametoindex`-style) used by the cloud-auth thread. Not
# NETLINK_KOBJECT_UEVENT — the uevent listener was opened at boot
# (visible in /proc/<pid>/net/netlink, not as a bind() in the trace).
#
# Zero new system-bus / sdbus-c++ private-bus connect()s in either pass.
# Persistent bus connections were already open at attach time.
